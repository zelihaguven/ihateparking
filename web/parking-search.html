HONEST LIMITATION

The accepted example is an intentionally spacious 5.0 m × 5.0 m bay so the current Hybrid A* baseline can verify and complete it. The compact 3 m example does not produce a verified route within the bounded search budget, so it remains stationary. This demonstrates a fail-closed decision; it does not establish performance in ordinary tight parking bays. Synthetic geometry, planner resolution, braking and uncertainty models still require validation before any real-system use.
